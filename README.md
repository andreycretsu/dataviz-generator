# Sankey Diagram Generator

An interactive Sankey diagram generator inspired by SankeyArt, built with D3.js.

## Features

- 📊 Interactive Sankey diagram visualization
- 🎨 Dual rendering modes: SVG and Canvas
- ✏️ Live data editor with table interface
- 🎛️ Customizable layout controls (size, node dimensions, spacing)
- 🔍 Balance validation and flow analysis
- 💾 Export capabilities
- 🎯 Click-to-edit nodes and flows

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open your browser to `http://localhost:8080`

## Usage

1. Use the data editor to add flows with From/To/Amount columns
2. Adjust layout settings (canvas size, node width/height, spacing)
3. Toggle between SVG and Canvas rendering
4. Click on elements to edit them directly
5. Export your diagram when done

## Technologies

- D3.js v7 for data visualization
- d3-sankey for Sankey diagram layout
- Vanilla JavaScript for interactivity
- Modern CSS for responsive UI
